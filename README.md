# Trusses Lab · Comnt Academy

Interactive lessons on truss analysis (Statics, Hibbeler Ch. 6): simple trusses, method of joints, method of sections and zero-force members. English UI, explanations in Egyptian Arabic. Static PWA — no build step.

- `index.html` app shell · `css/app.css` Comnt design tokens + components
- `js/truss.js` 2D truss solver + SVG renderer · `js/content.js` lessons, videos, models · `js/app.js` router & widgets
- `sw.js` offline cache · `manifest.webmanifest` install as an app
